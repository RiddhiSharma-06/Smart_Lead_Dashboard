# Smart Lead Dashboard

A full-stack MERN dashboard application for managing leads, analytics, and customer data efficiently.

## Features

- User Authentication (Login/Register)
- Lead Management
- Dashboard Analytics
- Responsive UI
- Protected Routes
- Role-Based Access
- Modern React UI
- REST API Integration

---

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Redux Toolkit

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Mongoose

## Installation

### Clone Repository

```bash
git clone https://github.com/RiddhiSharma-06/Smart_Lead_Dashboard.git
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the server folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
